How Node.js Works

  1. JavaScript code is written.
  2. V8 Engine converts JavaScript into machine code.
  3. Node.js executes the code.
  4. Heavy tasks like file reading or database access are sent to the system.
  5. The Event Loop keeps checking completed tasks.
  6. Completed results are returned using callbacks, promises or async/await.
Node.js is Single Threaded but it can handle many users simultaneously using the Event Loop and asynchronous programming.

S.No Method Description

2 Node REPL Execute JavaScript directly from the Command Prompt or Terminal.

1. Browser Console (console.log())

Before learning Node.js, we usually execute JavaScript inside the browser. Every modern browser provides Developer Tools where we can write JavaScript.

Steps:
  1. Open Google Chrome.
  2. Press F12 or Ctrl + Shift + I.
  3. Open the Console tab.
  4. Write JavaScript code.
console.log("Hello World");

console.log(name);
This method is mainly used for learning JavaScript and debugging browser applications.

2. REPL (Read Eval Print Loop)

REPL is an interactive environment provided by Node.js. It allows you to execute JavaScript code line by line without creating a file.

REPL Full Form
  • R → Read
  • E → Evaluate
  • P → Print
  • L → Loop
How to Open REPL?
  1. Open Command Prompt or Terminal.
  2. Type node.
  3. Press Enter.
  4. Now the terminal becomes a JavaScript environment.
C:\Users\User> node

>

> console.log("Hello")

Hello

> 10 + 20

30

> let age = 22

undefined

> age

22
How to Exit REPL?
  • Press Ctrl + C two times.
  • Or type .exit and press Enter.
When do we use REPL?
  • Quick testing of JavaScript code.
  • Learning JavaScript concepts.
  • Debugging small pieces of code.
  • Practicing Node.js commands.

It provides methods to create, read, write, update, rename, delete and manage files and directories.

📌 What is Data Fetching?

Data Fetching means requesting data from an API or server and using the response inside our application.

  • ✔ Built-in Node.js module (No installation required).
  • ✔ Used for making HTTP/HTTPS requests.
  • ✔ Event-driven (Streams).
  • ✔ Response data comes in chunks.
// Import HTTPS module
const https = require("https");

// Send GET request
https.get(url, (res) => {

    // Store incoming data
    let data = "";

    // Receive data chunk by chunk
    res.on("data", (chunk) => {
        data += chunk;
    });

    // Called when response is complete
    res.on("end", () => {
        JSON.parse(data);
    });

    // Handle errors
    res.on("error", (error) => {
        console.error(error);
    });

});

Node.js Modules (CommonJS & ES Modules) - Quick Revision

1️⃣ What is CommonJS?

CommonJS is the default module system used in Node.js (before ES Modules). It uses require() to import modules and module.exports to export data.

Export
// math.js

function add(a,b){
    return a+b;
}

function multiply(a,b){
    return a*b;
}

module.exports = {
    add,
    multiply
};
Import
const { add, multiply } = require("./math.js");

console.log(add(2,2));

2️⃣ What are ES Modules (ESM)?

ES Modules are the modern JavaScript module system. They use export and import keywords.

Export
export function add(a,b){
    return a+b;
}

export function multiply(a,b){
    return a*b;
}
Import
import { add, multiply } from "./math.js";

console.log(add(5,5));

3️⃣ Default Export

  • Only one default export is allowed per file.
  • Can be imported using any name.
// Export
export default function add(a,b){
    return a+b;
}

// Import
import adding from "./math.js";

console.log(adding(2,2));

4️⃣ Named Export

  • Multiple named exports are allowed.
  • Must be imported using the exported name.
// Export
export function add(){}
export function subtract(){}

// Import
import { add, subtract } from "./math.js";

5️⃣ Aliased (Renamed) Import

Use the as keyword to rename a named export while importing. 

import { subtract as s } from "./math.js";

console.log(s(10,5));

6️⃣ Import Entire Module

Import all exported members as a single object using * as. 

import * as math from "./math.js";

console.log(math.add(2,2));
console.log(math.subtract(5,2));
console.log(math.multiply(4,2));
